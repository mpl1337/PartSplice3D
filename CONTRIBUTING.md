# Beiträge

Fehlerberichte und nachvollziehbare Verbesserungsvorschläge sind willkommen.

Externe Code-, Grafik- oder Dokumentationsbeiträge werden derzeit nur nach
vorheriger ausdrücklicher Vereinbarung angenommen. Bitte keinen Pull Request
mit fremdem oder nicht eindeutig selbst geschaffenem Material einreichen.
Ein eingereichter Pull Request wird nicht automatisch übernommen.

Diese Regel schützt die eindeutige Rechtekette des Projekts. Bevor externe
Beiträge in PartSplice 3D einfließen, werden Herkunft, Lizenz und die für eine
einheitliche nichtkommerzielle sowie gegebenenfalls gesonderte kommerzielle
Lizenzierung benötigten Rechte schriftlich geklärt.
